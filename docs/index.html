Cryptography layer

Encrypted conversations with explicit limits

Ephemeral identities, authenticated packets and per-message keys. Temporary names are discovery labels, not proof of personal identity.

Symmetric Key Chains

HKDF-SHA256 chains derive a separate key for each message. This is not the full Signal Double Ratchet; compromise of a current chain key exposes future messages on that chain.

HKDF-SHA256Forward secrecy

ChaCha20-Poly1305 AEAD

Payloads are sealed and authenticated with modern AEAD. Nonces come from monotonic counters, and associated data binds both peer IDs — replayed or spoofed packets are rejected on arrival.

Anti-replayAuthenticated

Ephemeral Identity

Each conversation uses random libp2p and application identities. Choose a temporary display name without an account or password. Discovery and connection metadata can remain visible to network infrastructure.

Random identityEd25519

Best-effort Cleanup

Owned application key and file byte buffers are cleared on orderly close. Go, libraries and operating systems can retain copies; complete forensic erasure is not guaranteed.

Owned buffersKeepAlive

Zero Storage

No application chat database, configuration file or disk debug log. Files are written only when saved. Terminals, swap and crash dumps may retain information.

RAM-onlyNo persistence

Multiplexed file transfer

Files that never touch disk in transit

Drag a file into the terminal — or hit Ctrl+F for the built-in browser — and it streams over the same encrypted libp2p session as your chat. Files are split into 256 KB chunks, each hashed with SHA-256 as it flows.

The receiver assembles everything in RAM, independently recomputes the full hash, and rejects the transfer on any mismatch — zeroizing the buffer. Saving uses a private staging file and overwrite confirmation, with Unix owner-only 0600 permissions.

P2P routing & NAT traversal

Peer-to-peer with discovery and relay infrastructure.

Aegis runs on a fully decentralized topology over TCP and QUIC, multiplexed with Yamux. Messages are encrypted between peers. Public discovery and relay infrastructure can observe connection metadata.

Kademlia DHT

Peers resolve globally through distributed hash table routing anchored on bootstrap nodes.

mDNS Discovery

Peers on the same LAN use multicast DNS and live profile checks for name-based discovery.

NAT Hole Punching

AutoNAT and DCUtR attempt direct connectivity where the network permits it; restrictive NAT may require a relay.

Relay Fallback

Automatic circuit relays via public IPFS nodes when direct paths fail — still end-to-end encrypted. Bring your own with --relay.

Live walkthrough

From cold terminal to secure channel in four steps

01

Choose a temporary name

Run aegis and choose a temporary name. Random session identities are generated without a password.

02

Connect

Search the other person by name inside Aegis. Matching live profiles appear separately, including duplicate names.

03

Accept the request

The recipient accepts with Y or rejects with N. Requests expire after 60 seconds.

04

Chat, transfer, close

Exchange encrypted messages, choose files with Ctrl+F and save with Ctrl+S. Unsaved files are identified before interactive close.

Threat model

Designed against real adversaries

Every mitigation maps to a concrete attack. This is the model Aegis is built and tested against.

Passive eavesdropping
Double-encrypted wire transport — Yamux streams over TLS 1.3 QUIC, payloads sealed with ChaCha20-Poly1305.
Active man-in-the-middle
Authenticated transport identities and session-bound signatures. Person-level verification requires optional independent fingerprint/word comparison.
Replay & spoofing
Monotonic packet counters bound to unique AEAD nonces. Unsigned or duplicate-sequence packets are rejected.
Key compromise
Ephemeral signing keys and per-message symmetric chains. No in-session recovery after a chain-key compromise.
Cold-boot forensics
Owned byte buffers are cleared on orderly close; runtime copies, swap and forensic erasure are outside the guarantee.
Predictable identity
No master passphrase is required. Each conversation generates random keys.
Getting started

Install Aegis

One command per platform. The installer checks for Go, installs it via your package manager if missing, or falls back to a precompiled release binary.

# clone the repository
git clone https://github.com/rifatardarslan/Aegis.git
cd Aegis

Windows

Checks Go, auto-installs via winget, falls back to a precompiled aegis.exe from Releases, and wires up your PATH.

# double-click, or from a terminal:
.\install.bat

Linux & macOS

Works with apt-get, Homebrew, dnf and pacman. Installs to ~/.local/bin and adds it to your shell startup configuration. Open a new terminal to run aegis.

# run the installer:
chmod +x install.sh
./install.sh

Then just run it

aegis
--debugFixed diagnostic categories on stderr; no disk debug log
--relay "<multiaddr>"Prefer a custom circuit relay alongside public bootstrap/relay candidates
